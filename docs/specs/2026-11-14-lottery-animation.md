# 抽選のカプセル開封演出

ステータス: Implemented（2026-11-15）

単発・10連の抽選に、金色のカプセルが揺れ、光とともに上下に開くオリジナル演出を追加する。既存作品のキャラクター・画像・音声は使用しない。

- 抽選要求中は全画面の待機表示。成功後に約2.4秒の開封演出を再生する。
- 単発は当選報酬またはハズレを表示する。10連は当選報酬、ハズレの順に結果カードを表示する（実際の抽選順ではない）。重複当選も省略しない。
- 結果一覧はスクロール可能。当選件数とハズレ件数を常に表示する。
- スキップは演出だけを省略し、通信完了前には結果を表示しない。戻る操作も演出中はスキップ扱い、結果表示後は閉じる。
- エラー時は演出を終了し、既存のエラーメッセージを表示する。
- ダイアログが入力を遮断し、結果確認中の再抽選を防ぐ。演出は抽選UseCaseを呼ばない。
- 画面再生成後も確定した結果を表示する。表示済みの結果では開封を再生しない。
- Compose標準の描画・アニメーションを使い、外部ライブラリや画像素材は追加しない。

検証: 時間経過による結果公開、通信待ちでのスキップ、10連の重複結果・件数、画面再生成をCompose UIテストで確認する。

## 2026-11-15 改良

- 最新mainのサーバー抽選・要求復旧・一覧画面を維持して統合。復旧した結果も同じ演出で表示する。
- 約2.4秒を登場・浮遊、溜め、開封、余韻に分割。動きにイージングを使い、開封後はカプセルを徐々に消す。
- 紺とシャンパンゴールドを基調に、細い軌道・星・柔らかい光へ変更。紙吹雪は当選時だけ舞って消える。
- 結果カードは小さく持ち上がりながらフェードイン。単発結果は中央に配置する。
- 結果を閉じた後の一覧再取得中に、待機ダイアログが再表示されないようにする。
