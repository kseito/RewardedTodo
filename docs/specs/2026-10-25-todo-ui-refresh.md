## 1. 背景・目的

Todo一覧と詳細の視認性、チケット枚数の編集しやすさを改善する。提示されたデザイン案のカード、配色、枚数選択をAndroidの既存機能に合わせて取り入れる。

## 2. 要件

### 機能要件

- Todo一覧を角丸カードで表示し、タスク名、完了操作、獲得チケット枚数を読み取りやすく配置する。
- 詳細のBottomSheetでタスク名とチケット枚数を表示し、±操作と1・2・3・5枚の選択肢から設定できる。
- 共通の上部バー・下部ナビゲーションを含め、コーラルとゴールドを基調としたライト／ダーク配色を適用する。

### 非機能要件 / 制約

- 標準フォントを使う。文字サイズ拡大と小画面でも操作できる配置にする。
- タスク名はTodoistを正本とし、詳細では読み取り専用。チケット枚数は1〜100枚。
- Todoの追加・削除、所持チケット数、達成率、完了済み履歴は今回追加しない。
- 完了、同期、保存、エラー処理は既存の動作を維持する。

## 3. 画面・UX

- 対象: `TodoListScreen`, `TodoDetailBottomSheet`, 共通テーマ、上部バー、下部ナビゲーション。
- 一覧: カード左のチェック操作で完了、カード本体のタップで詳細を開く。右端にチケットアイコンと「+枚数」を表示する。
- 詳細: タスク名、獲得チケット枚数、±ボタン、プリセット、保存ボタンを縦に並べる。保存中は操作できず、成功後に閉じる。

## 4. ドメインへの影響

- 対象モデル: `Todo`, `EditingTodo`。
- ビジネスルールの変更なし。サーバー設定への保存とTodoist完了通知を既存のUseCase経由で行う。

## 5. レイヤー別の変更方針

| レイヤー | モジュール | 変更内容 |
|---------|-----------|---------|
| Common | `common:ui` | ライト／ダークのMaterial配色を定義 |
| Feature | `feature:todo` | 一覧カードと詳細BottomSheetのレイアウト、文言を更新 |
| App | `app` | 共通上部バーと下部ナビゲーションの配色・余白を更新 |

Domain、Application、Data、DIは変更しない。

## 6. 受け入れ条件

- [x] ライト／ダークで一覧カードのタスク名と獲得枚数を読める。
- [x] チェック操作でTodoが完了し、カード本体で詳細が開く。
- [x] 詳細で枚数を1〜100に保ち、±と1・2・3・5の選択肢から変更できる。
- [x] タスク名は編集できず、保存成功後に詳細が閉じる。
- [x] 保存中は重複操作できず、失敗時は入力を維持する。
- [x] 空状態、読み込み、更新、エラー表示が機能する。
- [x] 共通バーの配色がTodo・Rewardの両タブに適用される。
