# 報酬一覧・詳細のUI改善

- 作成日: 2026-10-27
- ブランチ: `codex/reward-ui-refresh`

## 目的と範囲

添付のUI改善案の報酬一覧・詳細を、対応済みのTodo画面と共通のMaterial配色・標準フォントで実装する。

- 一覧上部に所持チケット、単発・10連抽選をまとめた角丸パネルを配置する。
- 排出ラインナップの見出しに追加ボタンを配置する。リスト全体をスクロールでき、操作ボタンと項目が重ならない。
- 各報酬は角丸カードで表示する。名前、当選確率、レア度、リピート／1回限りを表示する。説明は詳細で表示・編集する。
- レア度は表示上の分類とする。確率0.2%以下はLEGEND、0.5%以下はEPIC、1%以下はRARE、それ以上はNORMAL。抽選計算は変更しない。
- 詳細はタイトル、名前、任意の説明、確率入力とスライダー、当選後もプールに残すスイッチ、保存・削除を配置する。新規追加時は削除を表示しない。
- スライダーは0〜100%、数値入力では既存の細かな確率をそのまま保存できる。入力欄とレア度表示を連動させる。
- 詳細は縦スクロール可能とし、小画面やキーボード表示中も操作できる。
- ライト／ダークに対応し、英語・日本語の文言を用意する。

## 維持する動作

追加上限7件、保存・削除、リピートの既定値、抽選・チケット消費、二重抽選防止、プル更新、エラー通知を既存のViewModel／UseCase経由で維持する。残高不足時は既存のエラー通知を使う。
抽選結果ダイアログと振動は既存の動作を維持する。資料にある抽選結果のアニメーション演出は今回の一覧・詳細刷新の対象外。
Domain／Application／Data／DIや保存済みデータは変更しない。

## 確認方針

- レア度の境界値、編集時のID・入力値・リピート、追加時の既定値、削除対象をテストする。
- 既存の報酬ViewModel／カードテストを実行する。
- ライト／ダークの一覧・詳細PreviewをRoborazziで描画して確認する。
- ビルド、Spotless、lint、独自detektルールで検証する。
