# Todo獲得枚数をサーバー管理にしTodo用Roomを廃止する

## 背景と課題
ローカルの獲得枚数がWebhookの固定1加算に反映されず、端末間でも共有できない。ローカルTodoは対象外で、通常処理にローカルDBは不要とユーザーから指定された。

## 検討した選択肢
- Roomをキャッシュとして維持する
- TodoistとReward Serverから取得し、画面状態をメモリだけに持つ

## 決定
後者を採用する。TodoistタスクIDとユーザーIDで獲得数を管理し、Webhookだけが残高を加算する。Todo名はTodoistを正本とし、アプリ詳細では獲得数のみ編集する。旧Todo用Roomの設定は移行せず破棄する。報酬DBと認証DataStoreは対象外。

### 結果・トレードオフ
起動後の一覧取得と編集には通信が必要。二重書き込みやキャッシュ同期は不要。設定保存は後から保存した値で上書きし、付与には配信IDの一意制約とDBトランザクションを使う。
